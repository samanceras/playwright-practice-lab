Repositorio de práctica para construir un framework de automatización QA con Playwright y TypeScript, aplicando el patrón Page Object Model (POM) para mantener los tests organizados, 
legibles y fáciles de mantener. Los casos de prueba se ejecutan sobre el sitio The Internet (Herokuapp), cubriendo escenarios como autenticación de usuarios, manejo de checkboxes y otros retos comunes de automatización web.
Creado por Sergio Mancera como laboratorio técnico y portafolio.

Practice repository for building a QA automation framework with Playwright and TypeScript, applying the Page Object Model (POM) pattern to keep tests organized, readable, 
and easy to maintain. Test cases run against The Internet (Herokuapp) site, covering scenarios such as user authentication, checkbox handling, and other common web automation challenges.
Created by Sergio Mancera as a technical lab and portfolio.
